数据是 NASA GISTEMP 全球年均气温距平（1880–2023，相对 1951–1980 基准）， 正负异色 + 5 年滑动均值线，标题、标注与刻度全部由数据现算。 本图用 renderDemo 在浏览器里渲染（canvas + hover）。 真正的看点是 render.cjs：在 Node.js 里用同一份 spec 无头跑数据流、导出 SVG， 并逐条核对 SVG 里的文字。试试在终端里执行：node src/21-node-headless-render/render.cjs

说明

本 demo 的 tickYears 是派生 signal（从数据年份区间每 20 年取一个刻度）， 没有交互控件。重点在 Node 端：render.cjs 读同一份 spec.vg.json，在无浏览器环境下跑完数据流， 用 view.toSVG() 导出矢量图到 output.svg （该文件在 .gitignore 里，不随仓库提交）。
